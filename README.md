# Experiment 6: Matrix Chain Multiplication

## 📌 Aim
To implement Matrix Chain Multiplication using Dynamic Programming and determine the optimal order of matrix multiplication.

## 📝 Description
This program finds the minimum number of scalar multiplications required to multiply a sequence of matrices. It also determines the optimal parenthesization and displays the Dynamic Programming cost table.

## 🛠️ Technique Used
- Dynamic Programming
- Tkinter GUI
